ラクダ家計簿 プライバシーポリシー

制定日：2026年9月26日

「ラクダ家計簿」（以下「本アプリ」）の開発者（以下「開発者」）は、本アプリにおける利用者の情報の取り扱いを以下のとおり定めます。

1. 基本方針

  • 本アプリには、開発者が運営するサーバーやアカウント登録の仕組みはありません。
  • 開発者は、利用者のレシート・家計・個人に関する情報を取得・保存・閲覧しません。
  • 本アプリは、広告、アクセス解析、トラッキングの仕組みを一切組み込んでいません。

2. 端末内に保存される情報

次の情報は、利用者の端末内にのみ保存されます。

  • レシート・支出の記録（店名、日付、商品名、金額、分類、支払い方法、メモなど）
  • 予算、固定費、収入、貯蓄目標などの家計の設定
  • 家族メンバーの呼び名、カスタム分類などの設定
  • 利用者が入力したAI事業者のAPIキー（端末のキーチェーンに保存）

これらは本アプリ内で削除できるほか、本アプリを削除するとすべて端末から消去されます。

設定の「データを書き出す」を使うと、これらの情報（APIキーを除く）を利用者が選んだ場所（「ファイル」アプリなど）にファイルとして保存できます。書き出したファイルの管理は利用者にお任せします。

3. 外部のAIサービスへの送信

本アプリの自動読み取りの機能は、利用者が設定で選んだ外部のAI事業者のAPIを、利用者自身のAPIキーで利用します。初めて使う前に、送信内容と送信先を説明した画面で同意をいただき、同意がない限り送信しません。同意は設定画面からいつでも取り消せます。

送信する情報レシート・領収書の写真、交通系ICカードの利用履歴のスクリーンショット、音声入力を文字にしたテキスト。これらには店名、商品名、金額、日付、駅名、医療機関名などが含まれることがあります。
送信先利用者が選んだ次のいずれかの事業者のAPI：Google（Gemini）、OpenAI、Anthropic（Claude）。開発者のサーバーは経由しません。
目的レシートの内容の読み取りと支出の分類のため

送信された情報は、各事業者のプライバシーポリシーと利用規約に従って取り扱われます。とくに Google Gemini API の無料枠では、送信した内容がGoogleのサービス改善（モデルの学習を含む）に利用される場合があります。

  • Google プライバシーポリシー／Gemini API 追加利用規約
  • OpenAI プライバシーポリシー
  • Anthropic プライバシーポリシー

4. 音声入力

音声入力では、Apple が提供する音声認識機能を利用します。音声の認識処理のために、音声データが Apple に送信される場合があります。その取り扱いは Apple のプライバシーポリシーに従います。本アプリが録音データを保存することはありません。

5. カメラ・写真へのアクセス

カメラと写真ライブラリには、利用者がレシートを撮影・選択したときにのみアクセスします。選択された画像のみを読み取りに使い、画像そのものは本アプリに保存しません。

6. 家族の端末との同期

家族同期の機能は、近くにある家族のiPhoneとローカルネットワーク（Wi-Fi・Bluetooth）で直接接続し、レシートと家計のデータを交換します。インターネットや開発者のサーバーは経由しません。APIキーは同期されません。

7. 通知

予算超過や固定費の確認などの通知は、端末内で作成されるローカル通知です。通知のために情報を外部へ送信することはありません。

8. 第三者提供

開発者は利用者の情報を取得しないため、第三者に提供することもありません。第3項の外部AIサービスへの送信は、利用者の同意と操作に基づき、利用者の端末から直接行われるものです。

9. お子さまの利用

本アプリは13歳未満のお子さまを対象としていません。

10. 本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。外部への送信内容や送信先を変更する場合は、本アプリ内で改めて同意をいただきます。
